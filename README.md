# 🌦️ Pune Weather Dashboard (Tableau)

## 📊 Overview

An interactive Tableau dashboard that analyzes weather patterns in Pune using dynamic visualizations. Users can explore temperature, humidity, wind, and seasonal alerts through real-time filtering.

---

## 🎯 Key Features

✨ Interactive bar chart filtering (click to update all graphs)
📈 Multi-chart dashboard (temperature, humidity, wind)
🌦️ Seasonal analysis (Monsoon, Winter, Heatwave)
⚡ Real-time dynamic updates across visualizations
🧭 Clean and user-friendly design

---

## 🖱️ How to Use

1. Click on any bar (Season / Alert)
2. Watch all charts update automatically
3. Clear selection to reset dashboard
